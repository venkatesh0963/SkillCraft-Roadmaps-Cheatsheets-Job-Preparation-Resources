# 🚀 SkillCraft

SkillCraft is a modern, responsive web platform offering structured **Roadmaps, Cheatsheets, and Career Preparation Resources** for developers. The entire project is styled using a vibrant **Neubrutalism** (Neo-Brutalism) design system, featuring bold borders, hard box shadows, and dynamic color palettes.

## ✨ Features.

- **🎨 Neubrutalism Aesthetic**: High-contrast borders, solid shadows, and a unique dotted background pattern.
- **🌓 Dark/Light Mode**: Seamless theme toggling with CSS variables.
- **🗺️ Interactive Roadmaps**: Step-by-step winding timeline for learning paths (e.g., Frontend Development).
- **💡 Developer Cheatsheets**: Grid-based layouts for quick syntax references (e.g., HTML5).
- **💼 Job Preparation Guides**: Detailed SEO-optimized guides including resume building with Google AdSense placeholders.
- **📱 Fully Responsive**: Optimized for desktop, tablet, and mobile devices using CSS Flexbox and Grid.

## 🛠️ Technology Stack

- **HTML5**: Semantic tags for accessibility and SEO.
- **CSS3**: Vanilla CSS utilizing Custom Properties (Variables), Flexbox, CSS Grid, and Media Queries.
- **JavaScript (Vanilla)**: For mobile menu toggling, theme switching, and scroll-to-top functionality.
- **Font Awesome**: Scalable vector icons.
- **Google Fonts**: Space Grotesk typography.

## 📂 Project Structure

- `skillcraft_neubrutalism.html` - The main landing page featuring navigation, hero section, and category links.
- `frontend_roadmap.html` - A comprehensive vertical timeline roadmap for aspiring Frontend Developers.
- `html_cheatsheet.html` - A categorized, vertical 1-column quick reference guide for HTML5 tags and attributes.
- `resume_guide.html` - An ATS-friendly resume building guide with integrated ad placeholders and related content grids.

## 🚀 How to Run

Since SkillCraft is built entirely with pure HTML, CSS, and JS, no complex build tools or dependencies are required.

1. Clone or download this repository.
2. Open any of the `.html` files directly in your web browser (e.g., double-click `skillcraft_neubrutalism.html`).
3. (Optional) Run a local development server for a better experience:
   - **Using VS Code**: Install the **Live Server** extension and click "Go Live".
   - **Using Python**: Run `python -m http.server 8000` in the terminal and visit `http://localhost:8000`.
   - **Using Node.js**: Run `npx serve .`
